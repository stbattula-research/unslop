Questions, annotated.

Everything people ask before they commit, answered in the margin.

01 Do I need a build step for the HTML versions? +

No. Each component is a plain .html file and a .css file. Open it in a browser and it works — fonts load from Google Fonts, everything else is local.

02 How do I install the React versions in my AI tool? +

Each component is a shadcn registry item. Run npx shadcn@latest add https://raw.githubusercontent.com/stbattula-research/unslop/main/r/<name>.json — or point your agent at SKILL.md and let it do the fetching.

03 Can I restyle a component? +

Yes, but read DESIGN.md first. The one rule: restyle toward a stronger point of view, never toward the defaults — no purple gradients, no glassmorphism, no centered pill-badge heroes.

04 What license is this under? +

MIT. Use it in commercial work, fork it, sell templates built on it. A star on the repo is appreciated but not required.
