Everything, indexed.

A short catalog of what this shelf holds — numbered the way a library would.

  1. 01

    Real type first Typography

    Serif display paired with a grotesk body and mono labels. Three voices, one page — the way print has done it for a century.

  2. 02

    Color with a spine Palette

    Ink, paper, and a single confident accent. Flat color fields instead of gradients that apologize for existing.

  3. 03

    Whitespace as punctuation Layout

    Generous margins and asymmetric grids. Nothing centered by default; every element earns its place on the page.

  4. 04

    Copy that sounds human Voice

    Microcopy written like a person, not a template. Buttons say what they do; footers admit what they are.
