The Taste skill: stops coding agents from producing generic "AI slop"
interfaces by enforcing concrete taste — distinctive typography, deliberate
color, and confident aesthetic choices. Single `SKILL.md`, prompt-driven (no
build step). It sits on Unslop's community shelf as reference material;
Unslop's own design judgment lives in `skills/design-intel/`.

The upstream repo also ships sibling style skills (`brutalist-skill`,
`minimalist-skill`, `soft-skill`, `redesign-skill`, `brandkit`, image-to-code
variants) — intentionally not vendored here; fetch the upstream repo for those.
