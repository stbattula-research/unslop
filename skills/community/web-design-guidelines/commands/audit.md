# /audit

Run a full design audit on the current project.

1. Find the main entry pages/components and styles.
2. Apply the audit skill checklist (hierarchy, typography, color, layout, components, polish).
3. Report pass/fail per section with file/line evidence.
4. List fixes ordered by user impact.

Ask before applying fixes, unless the user said "audit and fix".
