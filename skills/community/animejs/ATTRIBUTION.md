Anime.js is a vanilla-JavaScript animation engine (timelines, SVG
tooling, object tweens) — the no-framework counterpart to the shelf's
React-first motion skills. Sits on Unslop's community shelf as reference
material.

Note: `skills/community/animejs.md` is a separate, older linked
reference to BowTiedSwan/animejs-skills, an unlicensed third-party skill
pack that is not redistributed here. This folder supersedes it as the
shelf's Anime.js entry point; the linked file is kept for provenance.
